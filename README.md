# PARS-7

**Parhelion Adaptive Rocket System — 7th Iteration**

A portable, adjustable-angle model rocket launch pad designed to be 3D printed, lightweight, and packable. Folds down to clip onto the back of a backpack.

![Hero photo placeholder — replace with photos/hero.jpg](photos/hero.jpg)

## Features

- **Adjustable launch angle** — dual-hinge core body lets you launch from any angle, not just straight up
- **Two-legged design** — stable footprint without the bulk of a tripod
- **Packable** — folds into a compact assembly that clips to a backpack
- **Minimal hardware** — 3× M3 bolts, 3× M3 nuts, and a launch rod
- **Cheap to build** — almost entirely printed parts
- **Standard rod** — uses the Estes Maxi launch rod

## Safety

Model rocketry carries real risk. Always follow your national model rocketry safety code (e.g. [NAR Model Rocket Safety Code](https://www.nar.org/safety-information/model-rocket-safety-code/) in the US), launch in an open area clear of dry brush, keep spectators at a safe distance, and never modify motors. **PARS-7 is an unofficial DIY launch pad — you are responsible for verifying it is safe for your intended use before flying.**
